Everybody Codes
===============

My solutions to [Everybody Codes](http://everybody.codes), in Python.

Mainly for skills development. I make no claims that these are good solutions.


Running
-------
Inputs are not included in the repository (example data is). Download the inputs
manually and place them in the `input` directory (keep the default file name).

The simplest way to run these solutions is by using [`uv`](https://docs.astral.sh/uv):

    uv run src/ecerybody_codes_py_ft/[year]/[quest]/[filename].py

To run with example data instead, run:

    uv run src/ecerybody_codes_py_ft/[year]/[quest]/[filename].py example
